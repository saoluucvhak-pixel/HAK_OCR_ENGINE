# Model attribution

The pretrained MNIST CNN is from the ONNX model zoo, converted from the CNTK MNIST convolutional network tutorial. Model license identifier: MIT, as declared in the upstream model README.

Upstream model: https://github.com/onnx/models/tree/4c46cd00fbdb7cd30b6c1c17ab54f2e1f4f7b177/validated/vision/classification/mnist
Training source: https://github.com/microsoft/CNTK/blob/master/Tutorials/CNTK_103D_MNIST_ConvolutionalNeuralNetwork.ipynb
CNTK copyright and license: Copyright (c) Microsoft Corporation. All rights reserved. MIT License; see `LICENSE-CNTK-MIT.txt`.

The model is trained for isolated decimal digits. It is not a Vietnamese handwriting or name recognition model.
