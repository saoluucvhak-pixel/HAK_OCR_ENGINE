# Roadmap
1. Validate real PaddleOCR 3.x output with Vietnamese receipts and weighbridge tickets.
2. Test locally installed Baidu Unlimited-OCR model using SGLang on GPU; compare accuracy, latency, VRAM and PDF output.
3. Evaluate model-weight licensing separately from the MIT code license.
4. Expand tests with sample documents that contain no personal information.
5. Add optional offline Windows installer, local HAK app API and structured accounting document extraction.
6. Keep sensitive documents on local machine; no automatic upload or OCR cloud calls.
